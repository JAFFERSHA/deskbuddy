How people get it from GitHub

Example

Your GitHub page gets a Releases section. Each release lists the files to download, like this:

DeskBuddy-1.1.0-arm64.dmgMac
DeskBuddy-Setup-1.1.0.exeWindows

First run on a Mac

  1. Download the .dmg file and open it.
  2. Drag DeskBuddy into the Applications folder.
  3. Open it. macOS warns that it is from an unidentified developer.
  4. Go to System Settings, Privacy & Security, and choose Open Anyway. This is needed once.
  5. The buddy icon appears in the menu bar and the buddy walks in.

First run on Windows

  1. Download the .exe file and run it.
  2. Windows may show a blue "unknown publisher" box. Choose More info, then Run anyway.
  3. It installs in a few seconds and starts by itself.
  4. The buddy icon appears in the tray next to the clock and the buddy walks in.

Publishing through the Microsoft Store instead removes the warning, and is free.
