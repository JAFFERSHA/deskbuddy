# DeskBuddy for VS Code

A friendly animated character lives in the **DeskBuddy** view of the Explorer sidebar and reminds you to drink water, take breaks, stretch and rest your eyes.

- Three free characters: Mika, Arjun and Zoe
- Water, break, stretch, eye rest and one custom reminder, each with its own interval
- Desk pet mode: the buddy strolls around its view
- If the view is hidden, reminders arrive as normal VS Code notifications

Commands (Ctrl/Cmd+Shift+P): `DeskBuddy: Try a Reminder Now`, `DeskBuddy: Choose Character`, `DeskBuddy: Pause or Resume Reminders (1 hour)`, `DeskBuddy: Preview Pro (Coming Soon)`.

Settings are under **Settings > Extensions > DeskBuddy**.

Pro (your photo as a buddy, trending characters) is not available yet; the preview only records interest.
